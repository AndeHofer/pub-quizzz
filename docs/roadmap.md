# Pub Quizzz Roadmap

### Start page

- on the start page (index.html) the rankings should be shown.
- the rankings are the whole points of a team for every quiz it played
- best to worst tream
- there should also be a colum with the number of quizzes played, so we can see how many quizzes a team played and how
  many points they got

-admin user should see a botton which leads to the admin page.

### Admin page

on the admin page, the admin user should be able to:

- create a new quiz, edit or delete an existing
- create a new team, edit or delete an existing
- create a new user, or delete an existing
- create a new result, edit or delete an existing

### Quiz

a quiz has always 8 questions, the first 4 questions have 4 hints, the last 4 questions have 3 hints.

- a hint can be a text or an image or both.
