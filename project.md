# Project: Pub Quizzz

Pub Quizzz is a Spring Boot application designed to manage and run quizzes. It currently uses raw JavaScript and basic
CSS for the frontend, which is being migrated to a modern TypeScript, Tailwind CSS, and Vite-based architecture to
improve developer experience and frontend maintainability.

The project maintains a single-module Maven structure where the frontend build is integrated into the backend build
lifecycle.
