## INFO

A simple webpage to archive results, quiz and answers.

### Tech stack

:seedling:Spring Boot 4.x  
Java 25  
JUnit  
Mockito
Lombok  
MapStruct  
TypeScript  
Tailwind CSS  
Vite  
Axios

## How to run

Set these environment variables:

ADMIN_USER  
ADMIN_PASSWORD  
DEFAULT_USER  
DEFAULT_PASSWORD  
SPRING_DATASOURCE_USERNAME  
SPRING_DATASOURCE_PASSWORD  
SPRING_DATASOURCE_URL
